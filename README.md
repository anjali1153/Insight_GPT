# Insight_GPT
# AI-Powered Data Analysis Assistant

## Project Overview :
Insight_GPT is an AI-powered data analytics application developed using Python and Streamlit. The tool enables users to upload datasets and perform automated data analysis, visualization, and insight generation without requiring advanced technical knowledge.The application combines data preprocessing, statistical analysis, interactive dashboards, and AI-generated insights to help users understand their data quickly and make informed decisions.

## Features :
1. Data Upload
- Upload CSV files directly through the web interface.
- Supports datasets of varying sizes and structures.
- Automatic dataset preview after upload.

2. Data Summary
- Displays dataset dimensions.
- Shows column names and data types.
- Identifies missing values.
- Generates descriptive statistics.

3. Data Cleaning
- Detects null or missing values.
- Provides duplicate record identification.
- Supports basic preprocessing operations.

4. Exploratory Data Analysis (EDA)
- Dataset overview and structure analysis.
- Statistical summaries.
- Distribution analysis.
- Correlation analysis.

5. Interactive Visualizations
- Generate visual insights using:
- Bar Charts
- Line Charts
- Scatter Plots
- Histograms
- Pie Charts
- Correlation Heatmaps

6. KPI Dashboard
- Displays important business metrics:
- Total Records
- Total Columns
- Missing Values
- Numerical Features Count
- Categorical Features Count

7. AI-Powered Insights
- The system automatically generates:
- Key observations
- Data trends
- Statistical summaries
- Actionable business insights

7. User-Friendly Interface
- Built with Streamlit
- Interactive dashboard
- Simple navigation
- Real-time chart generation
